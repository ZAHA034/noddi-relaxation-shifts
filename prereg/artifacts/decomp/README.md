# Access logs of this study

`onharmony_image_access_log.json` and `external_data_access_log.json` are the access logs named in Supplementary Methods S-M7.1: every read of image data and every table and result file was logged in them with its time and SHA-256. In this deposit they start empty, and the code appends to them when you run it.

The released content of the original logs is `records/access_records.csv`, one row per logged file (the columns are described under «Notes» in the top `README.md`).

`wongkornchaovalit2025_sha256.txt` lists the SHA-256 and size of the 393 files of the copy of the Wongkornchaovalit et al. dataset (Science Data Bank) used in this study.
