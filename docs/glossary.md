# Glossary of Korean words in result files and code

Result files and code use Korean keys, values, labels and messages. They stay as they are because the code reads them, because the code is kept as it was run and because file hashes are recorded. This glossary gives the English for every one of them: the keys and values found in the JSON files of this repository, every Korean string literal in its Python code and the Korean words in the messages of its shell scripts. The other places where Korean remains, and where their English is, are listed under «Language» in `README.md`.
