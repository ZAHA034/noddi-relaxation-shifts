정의: `decomp/plans/S73_POST_HOC_PLAN_2026-11-16.md`(앞 커밋). 이 메모는 그 문서가 정하지 않은 구현 선택만 적는다. 정의 문서와 어긋나면 정의 문서가 앞선다. 이 메모의 커밋보다 앞서 §2–§5 의 어떤 양도 계산하지 않았다. 코드는 `decomp/explore/s73/` 에 두고 결과와 함께 커밋한다. 결과 파일은 `data/remeasure/explore/s73/` 꼴(작업 폴더 `<WORK>/remeasure/explore/s73/`)이다.

## 공통

- CPU 만. 시드는 분석마다 고정(아래). 실패 대조는 각 분석에서 먼저 돌리고, 기대대로 움직이지 않으면 그 분석은 값을 내지 않고 멈춘다(결과 파일에 대조 결과와 «멈춤» 만 쓴다).
- 읽기 기록: 파생 표(roi.json · 저장된 적합값)는 기존 로더가 남기는 다시 읽기 기록을 그대로 쓴다. 영상 · 영상에서 나온 지도 · 마스크 · 정합 파일을 읽는 §2 · §5 는 **읽기 전에 저자의 명시 승인**을 받고, 파일마다 읽기 전에 기록을 쓴다(기록을 쓸 수 없으면 읽지 않고 멈춘다). 승인 범위 밖의 파일은 읽지 않는다.
- 숫자는 장부 행으로 원고에 들어간다(새 ID 는 N-904 부터, A 가 매김).

## §3 적합기 출력의 조직 의존 이동

- 입력: 저장된 3 단계 E6 적합 표(`analyze3.load_table("E6")`, S1a 와 같은 로더) · 기준 조직 = `config.refs_e5()`(210) · 이완 설정 = S1a 의 17(`analyze3.lsets()["L1|cv0.03|rho0.0|iii"][0]`) · 생성기 셋 · 쌍 종류 Q1–Q4(기준 획득 A 대 Q). 칸 = 204.
- 좌표: x = logit ν, y = logit f_iso − ln ν(`lib.coords` 와 같은 정의). 적합값은 저장 표의 섬유 방향 평균 좌표(S1a 와 같음). raw NDI(ν_fit)는 적합 NDI 의 섬유 방향 평균.
- 참값: 기준 조직의 (ν, f_iso, ODI) 와 그 좌표 (x, y). (a) 의 설명 변수 = (x_true, y_true, ODI_true) + 절편, (b) 의 설명 변수 = (ν, f_iso, ODI) + 절편. 최소제곱(`numpy.linalg.lstsq`).
- Δ_max = 회귀 예측값(절편 포함)의 210 조직 안 최댓값 − 최솟값. 폭 = 1.96·√2·s.
- s: x 는 S1a 의 s_x_median(0.031, 저장 s1a.json 과 같은 계산), y 는 같은 계산(ON-Harmony OXF1PRI 재검사 SD 의 단위 중앙값)을 척도 y 로, raw NDI 는 척도 raw_ndi 로(`empirical.s_onh`).
- (b) 의 신호 모형 몫: 같은 칸의 이완 설정 · 두 획득의 TE · TR 로 식 (3) 의 겉보기 ν′ 를 내고 d_raw,model = ν′_Q − ν′_A 를 같은 설명 변수에 회귀.
- (c): 획득마다 x_fit,a 를 x_true 에 회귀(α_a, β_a, 최대 |잔차|) · 쌍마다 β_Q/β_A. 서술.
- 판독(정의 §3.4)은 x 에 적용한다(고정 문장이 logit NDI 에 대한 것). y 의 비율은 같은 표에 싣고, y 가 1 을 넘는 쌍 종류가 있으면 보충에 그대로 적는다. raw NDI 의 R′ = 칸 전체의 최대 비율.
- 실패 대조: (i) d = 명제 1 의 대수적 이동(칸의 ln(w_in/w_en) 상수)을 넣었을 때 절편 밖 계수 셋 모두 |·| < 10⁻¹⁰. (ii) (i) 의 d 에 0.10·(x_true − 평균) 을 더했을 때 x_true 계수 0.100 ± 10⁻⁶ 이고 Δ_max ÷ 폭 > 1. 둘 다 x 와 같은 코드 경로로.

## §4 음성 대조

- 입력: Tong roi.json(«주» 표) — rules_env 의 `_tong_scales` 와 같은 단위 차 · 문턱(t₀.₉₇₅(ν)·√2·s, s = c10r1–r3 의 단위별 재검사 SD) · 척도 x, y, odi, raw_ndi, logit_fiso. «비율» 은 공통 이동을 빼지 않은 값(고정 T-B 와 같은 값: x 0.931 · ODI 0.934 · y 0.844 를 먼저 재현하고, 다르면 멈춘다).
- 참가자별: 단위 = (센터 쌍, ROI) 중 그 참가자 것. 센터별: 그 센터가 낀 9 쌍 × 참가자 셋 × ROI.
- 동등성 경계: T₆(λ) 는 비중심 t(scipy.stats.nct, 자유도 6). 기대 비율 = P(|T| ≤ t₀.₉₇₅(6)). λ 를 비율에 대해 brentq 로 푼다(0 ≤ λ ≤ 10). δ/s = √2·λ·(σ/s) 를 σ = s 로 둔 값(정의 표의 δ/s = √2·λ). 관측 비율 셋(x, ODI, y)과 0.90 에 대해.
- 환산: δ(logit) = (δ/s) × 척도별 c10 재검사 SD 의 단위 중앙값. x 의 NDI 환산 = δ·ν(1−ν) 를 ν = 0.5 와 Tong ROI 중앙 NDI(전 세션 · 단위 raw NDI 의 중앙값)에서.
- 실패 대조 모의: 3 참가자 × 45 쌍 × 27 ROI = 3,645 단위. ROI 마다 s² ~ σ²·χ²₆/6 을 한 번 뽑아 그 ROI 의 135 단위가 같이 쓴다. 차 ~ N(δ, 2σ²), σ = 1. 반복 1,000 · 시드 20261116. 기준: δ = 0 → 평균 0.95 ± 0.005 · δ = 1.086 → 0.90 ± 0.005 · δ = 2 → < 0.80.
- y 진단: 단위(ROI) 평균 FISO = Tong 전 세션(r1 센터 열과 c10 반복 셋)의 raw FISO 평균. 단위의 재검사 수준 비율 = 그 ROI 의 모든 (참가자, 쌍) 단위 중 비율. Kendall τb(scipy.stats.kendalltau, variant b) · 중앙값 아래 · 위 단위 묶음의 비율(묶음의 모든 단위 차를 합쳐 셈). 중앙값과 같은 단위는 «위» 에 넣는다. x · logit_fiso 도 같게.

## §2 다중 TE 정합 (읽기 승인 뒤)

- 계열: 기준 = TE62(첫 62 ms), 나머지 9 = TE72 … TE132, TE62R2, TE132R2. 참가자 sub-01 · 02 · 03.
- 2.1: 고정 검사와 같은 함수(`run.py` 의 `mean_dw_ratio` · `align_r`, 기준 계열의 뇌 마스크)로 r 을 다시 낸다. 낮은 b0 화소 = 기준 계열 b0 평균의 마스크 안 하위 1 %(np.percentile, 기준만으로 정함). 같은 마스크에서 그 화소를 뺀 r 도 낸다. 원 자료(제공자 dwi)를 읽어야 한다.
- 2.2: 입력 = 처리 때 만든 평균 b0(기준 `wong/<sub>/b0_mean.nii.gz`, 계열 `own_<계열>/b0_mean.nii.gz`)와 기준 뇌 마스크. `flirt -in 계열 -ref 기준 -dof 6 -cost normmi -searchcost normmi -omat`(그 밖은 FSL 기본값). 변위 = 마스크 안 화소 중심 p(FSL 스케일 mm 좌표)에서 |M·p − p| 의 최댓값. 복셀 크기 = 계열 pixdim 셋 가운데 가장 작은 값(정렬됨 판정을 엄하게). 대조 (ii) 의 2 복셀 이동 = 정수 화소 이동(가장자리는 0), x 축 = 영상 첫 축, 변위는 그 축 pixdim 으로 나눈 값.
- 경로 B · C 의 지도: 처리 때 계열마다 원 공간에 만든 F2 지도 일곱과 적합 유효 지도 둘(`own_<계열>/f2_<계열>_*.nii.gz`). 표준 공간으로 보내는 정합 = 기준 계열의 `fa2std_warp`, 뇌 마스크 = 기준 계열 마스크(nn), 그 밖은 `to_std_and_roi` 와 같은 명령 · ROI 함수. 경로 C 는 같은 applywarp 에 `--premat=<2.2 의 계열→기준 행렬>`. 기준 계열 자신도 새 코드로 다시 내서 저장된 `roi_TE62.json` 과 같은지 먼저 본다(다르면 멈춤).
- 다시 계산: 경로마다 `wong/<sub>/` 꼴의 별도 작업 폴더(DONE.json 의 «따로_정합» = 빈 목록, 경로 B 는 통과 계열의 roi 만)를 만들고, 기존 코드(judge_wong.judge · S10 의 ODI 범위 비 · S-M8.3 의 기울기 · rules_env e1 · e1_fix · e4 · e5 · e6)를 REMEASURE_WORK 를 그 폴더로 돌린다. 코드 차이는 정합 단계뿐(보고).
- §5.4 의 β: E1 의 참가자별 β 와 그 95 % 부트스트랩 구간(e1 과 같은 함수). 첫 두 줄의 조건 = 세 참가자 모두 β > 0 이고 구간이 0 을 포함하지 않음. 셋째 줄 = 적어도 한 참가자의 구간이 0 을 포함하고, β < 0 이며 구간이 0 을 포함하지 않는 참가자가 없음. 그 밖의 꼴은 문장을 고르지 않고 보고한다.

## §5 다중 TE 잡음 바닥 (읽기 승인 뒤 SNR)

- 조직 상태: S1b 의 ROI 대응 단위(참가자 × ROI, TE62 관측값을 중심 이완에서 식 (3) 으로 역산) · 중심 이완 · 생성기 T-in · TR 5.8 s · 방향 scheme = S1b 와 같은 카드(WONG:TE<n>).
- 복셀 200: 섬유 방향 넷(FDIR_E5)에 50 개씩. 신호 = synthfit 의 무잡음 식 그대로 × 1000(b0 = 1000).
- 잡음: 비중심 χ, L ∈ {1, 4, 16}. 채널마다 신호 S/√L, 실 · 허 성분 잡음 N(0, σ²), 크기 = √(Σ 채널 |·|²). σ = 1000 / SNR(참가자, TE). 시드 = 20261116 + 참가자 번호 × 1000 + L.
- SNR: 참가자 · TE 별 `analysis.snr`(S-M6). sub-01 은 저장된 `b1s_snr.json`. sub-02 · 03 은 기록이 없으면 원 자료의 b0 부피를 읽어야 한다(승인 범위). 승인이 없으면 sub-01 의 TE 별 값을 세 참가자에 쓰고 그렇게 보고한다.
- 적합: synthfit.fit_chunk(AMICO F2 그대로). 단위 값 = 복셀 200 적합값(NDI · FWF · ODI)의 평균 → 좌표.
- 양(Monte Carlo 50 의 각 반복에서 내고 반복 평균 · 범위): 단위의 x · y TE 기울기(OLS), τ_sim = √max(0, Var_단위(반복 평균 기울기) − 평균_단위(반복 사이 분산)/50) 과 보정 전 값, β_sim = E1 과 같은 `beta_level`(단위 평균 수준), 고정 선형 규칙(judge_wong)의 비율, ODI 범위 비(분모 = 두 반복의 TE62 · TE132 차의 단위 중앙값), 궤적 방향 = atan2(k_y, k_x) 의 단위 중앙값.
- 대조: (i) SNR = ∞(잡음 없음, 반복 1)에서 τ_sim 이 S1b 의 적합기 단독 값(T-in · 중심 이완 x)과 ±10 % 안. (ii) SNR = 5 · L = 1 에서 단위 평균 NDI 또는 FISO 의 무잡음 대비 이동이 재검사 폭(1.96·√2·s, s = 다중 TE 반복 SD)보다 큰 단위가 있다.
- τ_obs = 경로 A · B · C 의 E1 고친 합친 τ_x(e1_fix) 가운데 가장 작은 값.
