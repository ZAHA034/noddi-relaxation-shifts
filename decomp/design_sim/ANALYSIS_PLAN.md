# 다기관 설계 시뮬레이션 — 분석 계획(계산 전에 고정)

작성 2026-11-17. 원고의 등급으로 **post hoc**(판정 뒤에 정의하고, 계산 전에 고정)이다. 입력은 모두 가정 값이므로 결과는 원고에서 «illustration» 과 함께 쓴다. 어떤 판정도 다시 열지 않는다. 실자료를 읽지 않는다(신호 모형 수준의 시뮬레이션). 이 문서를 저장소에 커밋한 뒤에만 본 실행을 한다. 실행 전에 바꿔야 하면 바꾼 곳과 이유를 이 문서 끝 «바꾼 기록» 에 적고 다시 커밋한다. 실행 뒤에는 바꾸지 않는다. 시간을 재는 시범 실행은 하되 그 지표 값은 열어 보지 않는다.

근거: 검토 방향 S81 6 절과 S82 2 절(검토 세션 제안, 저자 승인), A 의 고침 넷(S1 효과 크기 · 반복 단위 몬테카를로 SE · K-d 설정 기록 · ComBat 구현과 M4).

## 1. 목적

응용 독자의 물음: 집단의 구획 이완이 다르고 사이트의 TE 가 다를 때, 표준 ComBat 분석이 분율만의 집단 차이를 얼마나 틀리게 추정하고 그 신뢰구간이 맞는가, 그리고 group × TE 항이나 이완 측정이 무엇을 바꾸는가. 원고의 명제 4 시뮬레이션(보충 S-M9)에 없던 사람 사이 변동 · 경험적 베이즈(EB) ComBat · 불균형 사이트를 넣는다. 결과의 대부분은 대수(명제 4, 식 (7), 2.4 절)로 정해지며, 이 시뮬레이션은 그 크기를 신뢰구간 · 검정의 말로 옮긴다.

## 2. 자료 생성 모형(로짓 척도 · 사람 i, 사이트 s, ROI 단위 r)

- 참 분율: logit ν_isr = logit ν_r + θ·g_i + b_ir. g_i = 1 환자, 0 대조. 사람은 한 사이트에서만 찍는다.
- ROI: 27 단위. ν_r = 0.45 에서 0.80 까지 같은 간격(가정; 로짓 척도의 분석에는 영향이 없고 원척도 분석 M1r 에만 쓰인다).
- 사람 사이 참 분율 변동: b_ir = 0.08·(√ρ·z_i + √(1 − ρ)·z_ir), z ~ N(0, 1), ρ = 0.5(ROI 사이 상관, 가정). 사람 사이 SD 0.08 logit 은 보충 S-M9.7 과 같은 값(가정).
- 이완(대조): T2,in 82.5 ms, T2,en 52 ms(2.4 절). 환자: 배정된 구획의 T2 × 1.0984(2.4 절의 미만성 연장, Brandhofe et al., 2021).
- 사람 사이 이완 변동(요인 V): 사람마다 T2,in 과 T2,en 에 로그정규 배수, 변동계수 v(로그 SD √ln(1 + v²)), in–en 상관 0.8(가정). 사람 전체에 하나(ROI 공통).
- T1 · 양성자 밀도: 집단 공통(명제 4 의 조건). 조직 두 구획이 T1 을 공유(S-M2 의 중심 값)하므로 logit NDI 의 TR 항은 0 이고, TR 은 기록만 한다.
- 겉보기: logit ν_app,isr = logit ν_isr + TE_s·(R2,en,i − R2,in,i), R2 = 1/T2(ms⁻¹).
- 관측: y_isr = logit ν_app,isr + γ_sr + δ_sr·ε_isr + η_s·g_i.
  - ε ~ N(0, 0.031²): x 의 OXF1PRI 재검 SD(원고 4.1).
  - γ_sr = 제조사 평균(Siemens 0, Philips +0.10, GE −0.10 logit; 가정) + 사이트 · ROI 편차 N(0, 0.05²)(가정; 반복마다 새로 뽑음).
  - δ_sr = exp(N(0, 0.1²))(가정; 반복마다).
  - η_s: 이완과 무관한 사이트 × 집단 항(요인 H).
- 적합기를 거치지 않는다(신호 모형 수준). 적합기 효과(보충 S-M9 의 1.00–1.30 배)와 잡음 바닥은 넣지 않으며, 결과 문단에 한계로 적는다.

## 3. 설계 요인(칸 = D × S × V × H × N = 3 × 8 × 2 × 3 × 2 = 288)

획득(ON-Harmony 8 획득, 고정 문서의 카드 표; TE 는 범위의 가운데 값, 보충 S-M9.7 과 같음):

| 획득 | 제조사 | TE (ms) | TR (s) |
|---|---|---|---|
| OXF1PRI | Siemens | 92.0 | 3.60 |
| OXF2PRI | Siemens | 92.0 | 3.60 |
| OXF3TRI | Siemens | 96.4 | 3.60 |
| NOT2ING-89 | Philips | 89.0 | 4.00–4.38 |
| NOT2ING-98 | Philips | 98.0 | 4.00–4.38 |
| NOT4GEP | GE | 68.0 | 4.90 |
| OXF4GEP | GE | 69.65 | 8.00 |
| NOT1ACH | Philips | 70.6 | 9.81–10.62 |

- D 사이트 설계: D1 위 표 그대로(긴 TE 는 Siemens 와 NOT2ING). D2 같은 여덟 TE 를 제조사마다 짧은 TE 와 긴 TE 가 다 있게 재배치 — Siemens 사이트(OXF1PRI, OXF2PRI, OXF3TRI) 68.0 · 92.0 · 98.0, Philips 사이트(NOT2ING-89, NOT2ING-98, NOT1ACH) 69.65 · 89.0 · 96.4, GE 사이트(NOT4GEP, OXF4GEP) 70.6 · 92.0. D0 여덟 사이트 모두 TE_c = 여덟 TE 의 평균 84.45625 ms(대조).
- S 시나리오(ΔR2 = 환자 − 대조, ms⁻¹; Δ = ΔR2,en − ΔR2,in):
  - S0 차이 없음(θ = 0, 이완 같음).
  - S2b 이완만, 두 조직 구획 연장(Δ_b = −0.000636909 ms⁻¹, 보충 S-M9.7 의 기울기). S2e 이완만, 신경돌기 밖만(Δ_e = −0.001722786). S2i 이완만, 신경돌기 안만(Δ_i = +0.001085877). θ = 0.
  - S1b 분율만, θ = TE_c·Δ_b(중앙 TE 에서 S2b 와 같은 겉보기 차이, 약 −0.0538 logit). S1e 분율만, θ = TE_c·Δ_e(약 −0.1455 logit).
  - S3b = S1b 의 분율 + S2b 의 이완. S3e = S1e 의 분율 + S2e 의 이완.
  - S1 의 크기를 다른 질환의 보고 값이 아니라 겉보기 차이에 맞춘 것은, 한 사이트에서 구별되지 않는 두 원인을 나란히 보이려는 것이다.
- V: v = 0 또는 0.10.
- H: H0 없음. H1 η_s ~ N(0, 0.02²)(반복마다). H2 Siemens 사이트의 환자에 +0.02 logit(제조사와 엮인 항).
- N: 균형 — 사이트마다 집단당 20 명(사이트 40 명, 모두 320 명). 불균형 — 사이트마다 40 명, 환자 수 OXF1PRI 12 · OXF2PRI 28 · OXF3TRI 16 · NOT2ING-89 24 · NOT2ING-98 20 · NOT4GEP 20 · OXF4GEP 28 · NOT1ACH 12(비율 0.3–0.7). D2 · D0 에서도 사이트 이름에 붙은 수를 쓴다.
- 반복: 칸마다 1,000 회. 씨앗: numpy SeedSequence([20261117, 칸 번호]) — 칸 번호는 위 순서(D, S, V, H, N)의 사전식 차례.

## 4. 분석(ROI 단위마다 따로; 집단 계수의 95 % 구간은 t 분포)

| ID | 분석 | 보고 |
|---|---|---|
| M0 | 사이트 무시: y ~ group(OLS) | θ̂ |
| M1 | 표준 ComBat: neuroCombat 0.2.12(EB, parametric, group 을 범주 공변량으로 보존, 27 ROI 를 특징으로), 로짓 척도 → OLS ~ group | θ̂ |
| M1c | 대조군만으로 학습한 ComBat(Jodoin et al., 2025 의 권고): 대조군만으로 neuroCombat(EB, 공변량 없음)을 학습하고, 그 추정치를 모든 참가자에 같은 식으로 적용(저장소 `decomp/rules_env/analyses.py` 의 `combat_apply`, neuroCombatFromTraining 0.2.12 와 같은 식) → OLS ~ group | θ̂ |
| M1r | 원척도 NDI 에 M1 과 같은 ComBat → OLS ~ group | 원척도 θ̂ |
| M2 | y ~ group + site(고정) | θ̂ |
| M3 | y ~ group + site + group × TE_s(TE 중심화하지 않음) | θ̂(TE→0) = group 계수 · θ̂(TE_c) · group × TE 검정 |
| M4 | 2 단계 무작위 효과 메타회귀: 사이트별 집단 차이 d_s(사이트 안 OLS)를 TE_s 에 회귀, 사이트 사이 분산 τ² 는 적률법(DerSimonian–Laird 의 회귀판), 가중 1/(v_s + τ̂²), 절편 = θ̂(TE→0), 구간은 t(사이트 수 − 2) | θ̂(TE→0) · 기울기 검정 · τ̂² = 0 인 몫 |
| M5a · M5b | 이완 측정: 사람마다 R2,in · R2,en 을 재어 식의 이완 항 TE_s·(R̂2,en − R̂2,in) 을 뺀 뒤 M2. M5a 측정 오차 없음(기준), M5b 각 R2 에 독립 로그정규 오차 CV 10 %(가정) | θ̂ |

- M4 는 S81 의 혼합모형(REML)을 대신한다: 잠금 환경에 statsmodels 가 없고, 패키지를 더하면 기탁 잠금 파일이 바뀐다. 사이트 × 집단 변동을 무작위 효과로 두는 목적은 같다. 계산이 가벼워 모든 칸에서 돌린다.
- M5 는 «이완을 재면» 의 상한과 현실 값을 보이는 기준 분석이다. 원고 글에서 이 분석을 restore · remove · correct 로 부르지 않는다.

## 5. 추정 대상과 지표

- 추정 대상 θ: 집단 사이 참 분율 차이(로짓, 이완 없음). S0 · S2 에서 θ = 0. M1r 의 대상은 ROI 마다 원척도의 참 차이 E_b[expit(logit ν_r + θ + b) − expit(logit ν_r + b)], b ~ N(0, 0.08²)(가우스–에르미트 40 점).
- 지표(분석 · 칸마다): 편향, 경험 SD, 모형 SE 의 평균, RMSE, 95 % 구간 포함률, H0: θ = 0 의 기각률(양측 0.05; S0 · S2 에서는 거짓 양성, S1 · S3 에서는 검정력), M3 · M4 의 group × TE(기울기) 기각률, M4 의 τ̂² = 0 몫.
- ROI 에 걸친 요약: 반복마다 27 ROI 의 값(오차 · 포함 여부 · 기각 여부)을 평균한 뒤 반복에 걸쳐 평균한다. 몬테카를로 SE 는 반복 단위 값의 SD / √1000(ROI 사이 상관을 반영). 경험 SD 는 ROI 마다 반복에 걸쳐 계산해 평균한다. ROI 별 값은 기탁 결과 파일에 둔다.

## 6. 실행 전에 고정한 읽기(결과가 어느 쪽이든 이 틀대로 쓴다)

- R-a(D1 · H0 · V0 · 균형): S2e 와 S2b 각각에서 M1 의 포함률이 0.90 미만이면 «a standard ComBat analysis in this design does not give valid intervals for the fraction-only difference», 0.90 이상이면 «the within-site bias was small against sampling error at this size».
- R-b(같은 칸): b, e 각각에서 S2x 의 M3 θ̂(TE→0) 포함률이 0.93 이상이고 S1x 에서 그 검정력이 0.50 미만이면 «extrapolation to TE → 0 is valid but imprecise in this design». 그 밖에는 값을 그대로 보고한다.
- R-c: D2 와 D1 의 M3 θ̂(TE→0) SE 와 검정력 차이를 설계 조언(«TE spread within vendor»)으로 보고한다. 기술(記述)만.
- R-d: H2 · S0(D1 · V0 · 균형)에서 M3 의 group × TE 기각률(제조사 혼재로 생기는 거짓 양성)을 보고한다. 기술만.
- 인쇄: 보충 표에는 균형 · H0 · H2 · 모든 D · V · S 의 칸(96 칸)에 M1 · M1c · M2 · M3 · M4 · M5b 의 편향 · 포함률 · 기각률을 싣고, 288 칸 전체(모든 분석 · 지표 · ROI 별 값)는 기탁 결과 파일과 표로 둔다(S81 은 전체를 보충 표로 제안 — 보충 분량 때문에 나눔).

## 7. 반드시 실패해야 하는 검사(본 실행보다 먼저 돌리고 출력 · 심은 결함의 실패를 기록)

- K-a 잡음 없는 대수: ε, b, v, η, γ 를 0 으로, δ = 1 로 두고 칸마다 사이트별 집단 평균 차이가 θ + TE_s·Δ 와 1e−10 안에서 같아야 한다(S1 · S2 · S3 모두, D0 · D1 · D2). 심은 결함: 생성기에서 TE 항을 뺀다 → 실패해야 한다.
- K-b 영가설 보정: D0 · S0 · H0 · V0 · 균형에서 M2 포함률이 0.929–0.971(0.95 ± 3 MC SE) 안. 심은 결함: SE 를 절반으로 → 실패해야 한다. M1 의 같은 칸 포함률은 검사가 아니라 결과로 보고한다.
- K-c 해석적 편향: D0 · S2e · H0 · V0 · 균형에서 M2 의 편향이 TE_c·Δ_e 와 3 MC SE 안. 대조: T2 를 늘리는 대신 같은 비율로 줄이면 편향의 부호가 바뀌어야 한다(같은 검사를 원래 기댓값에 대어 실패해야 한다).
- K-d 기존 값과의 일관성: 보충 S-M9.7 의 설정 — D1 · H0 · V0 · 균형, ε = 0 · δ = 1 · γ 의 사이트 편차 0(사람 사이 SD 0.08 만), 여덟 TE 의 가운데 값 — 에서 M3 의 group × TE 기각률이 S2b 에서 0.136, S2e 에서 0.634(저장된 z 검정 값, `ledger/derived/s75_values.json` power.by_te.mid)와 3 MC SE 안. 재현되지 않으면 멈추고 보고한다. 맞추려고 코드를 고치지 않는다(원인이 기존 계산 쪽이면 그 사실을 적는다). 심은 결함: 효과를 0 으로 → 기각률이 0.05 근처로 떨어져 실패해야 한다.
- K-e ComBat 구현: 대조군만이 아니라 모든 참가자로 학습해 `combat_apply` 로 같은 자료에 적용하면 neuroCombat 0.2.12 의 출력과 1e−10 안에서 같아야 한다(공변량 없는 학습). 심은 결함: EB 축소를 끈다(γ*, δ* 대신 γ̂, δ̂) → 실패해야 한다.
- 다섯 검사의 출력(통과 · 실패 줄, 심은 결함에서의 실패)을 결과 폴더의 `checks.json` 에 둔다.
